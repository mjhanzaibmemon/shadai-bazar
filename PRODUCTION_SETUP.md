## DEPLOYMENT OPTIONS

### Option 1: VERCEL (Recommended - Easiest)

**Advantages:**
- Zero-config deployment
- Auto-scaling
- Free SSL certificates
- GitHub integration
- Auto-deploys on push

**Steps:**

1. **Install Vercel CLI**
   ```bash
   npm install -g vercel
   ```

2. **Login to Vercel**
   ```bash
   vercel login
   ```

3. **Test Build Locally**
   ```bash
   npm run build
   npm run lint
   ```

4. **Deploy to Vercel**
   ```bash
   vercel --prod
   ```

5. **Configure Environment Variables**
   - Go to Vercel Dashboard → Project Settings → Environment Variables
   - Add:
     - `MONGODB_URI`: Your MongoDB Atlas connection string
     - `JWT_SECRET`: Your JWT secret key
     - `NEXT_PUBLIC_API_URL`: Your Vercel deployment URL
     - `NODE_ENV`: `production`

6. **Setup Custom Domain**
   - Vercel Dashboard → Settings → Domains
   - Add your domain
   - Update DNS records at registrar
   - Wait 24-48 hours for propagation
   - SSL auto-generated by Vercel

**Cost:** Free tier or $20/month paid depending on usage

**Automated Script:**
```bash
chmod +x deploy-vercel.sh
./deploy-vercel.sh
```

### Option 2: VPS (DigitalOcean/Linode/AWS)

**Advantages:**
- Full control
- Better for customization
- Can host multiple apps
- Cheaper at scale

**Requirements:**
- VPS with 2GB+ RAM (DigitalOcean: $6/month)
- Linux (Ubuntu 20.04+ recommended)
- Domain name
- 30 minutes setup time

**Automated Deployment:**
```bash
chmod +x deploy-vps.sh
./deploy-vps.sh
```

**Manual Steps:**

1. **SSH into VPS**
   ```bash
   ssh root@YOUR_VPS_IP
   ```

2. **Update System**
   ```bash
   apt update && apt upgrade -y
   ```

3. **Install Dependencies**
   ```bash
   # Node.js
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   apt install -y nodejs

   # PM2 (process manager)
   npm install -g pm2

   # Nginx (reverse proxy)
   apt install -y nginx

   # Git
   apt install -y git

   # Let's Encrypt (SSL)
   apt install -y certbot python3-certbot-nginx
   ```

4. **Clone Repository**
   ```bash
   git clone https://github.com/YOUR_USERNAME/shaadi-bazaar.git /home/deploy/shaadi-bazaar
   cd /home/deploy/shaadi-bazaar
   ```

5. **Setup Environment**
   ```bash
   cp .env.example .env.production
   # Edit with production values
   nano .env.production
   ```

6. **Install & Build**
   ```bash
   npm install
   npm run build
   ```

7. **Setup PM2**
   ```bash
   # Create ecosystem.config.js
   cat > ecosystem.config.js << 'EOF'
   module.exports = {
     apps: [{
       name: 'shaadi-bazaar',
       script: 'node_modules/.bin/next',
       args: 'start',
       instances: 'max',
       exec_mode: 'cluster',
       env: {
         NODE_ENV: 'production',
         PORT: 3000
       }
     }]
   };
   EOF

   # Start with PM2
   pm2 start ecosystem.config.js
   pm2 startup
   pm2 save
   ```

8. **Configure Nginx**
   ```bash
   # Edit Nginx config
   sudo nano /etc/nginx/sites-available/default
   
   # Replace with:
   server {
     listen 80;
     server_name yourdomain.pk;

     location / {
       proxy_pass http://localhost:3000;
       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection 'upgrade';
       proxy_set_header Host $host;
       proxy_cache_bypass $http_upgrade;
     }
   }
   
   # Test and reload
   sudo nginx -t
   sudo systemctl restart nginx
   ```

9. **Setup SSL**
   ```bash
   sudo certbot --nginx -d yourdomain.pk -d www.yourdomain.pk
   # Auto-renewal will be configured
   ```

10. **Setup Firewall**
    ```bash
    ufw enable
    ufw allow 22/tcp
    ufw allow 80/tcp
    ufw allow 443/tcp
    ```

**Cost:** $6-12/month for VPS + domain

**VPS Providers:**
- DigitalOcean: https://digitalocean.com
- Linode: https://linode.com
- AWS: https://aws.amazon.com
- Vultr: https://www.vultr.com

## MONGODB ATLAS SETUP

1. **Create Account**
   - Go to https://mongodb.com/cloud/atlas
   - Sign up with email

2. **Create Cluster**
   - Click "Create" cluster
   - Select "Free M0 Shared Cluster"
   - Choose region closest to you (Asia)
   - Click "Create Cluster"

3. **Configure Database**
   - Create database user (username/password)
   - Whitelist IP addresses
     - For development: Your IP
     - For production: Your VPS IP
     - Or: 0.0.0.0/0 (allow all, less secure)

4. **Get Connection String**
   - Click "Connect"
   - Select "Connect your application"
   - Copy connection string
   - Replace `<password>` with your password
   - Format: `mongodb+srv://user:pass@cluster.mongodb.net/shaadi-bazaar`

5. **Enable Backups**
   - Cluster → Backup Settings
   - Enable "Auto-Backup"
   - Set backup frequency to daily

## IMAGE UPLOAD (CLOUDINARY)

1. **Create Cloudinary Account**
   - Go to https://cloudinary.com
   - Sign up (free tier includes 25GB/month)

2. **Get API Credentials**
   - Dashboard → API Keys
   - Note: `Cloud Name`, `API Key`, `API Secret`

3. **Update Backend**
   ```bash
   npm install next-cloudinary
   ```

4. **Configure Environment**
   ```
   NEXT_CLOUDINARY_CLOUD_NAME=your_cloud_name
   NEXT_CLOUDINARY_API_KEY=your_api_key
   NEXT_CLOUDINARY_API_SECRET=your_api_secret
   ```

5. **Update Upload API**
   - Replace base64 implementation with Cloudinary API
   - Update `src/app/api/upload/route.ts`

## EMAIL SERVICE (SENDGRID)

1. **Create SendGrid Account**
   - Go to https://sendgrid.com
   - Sign up (free tier: 100 emails/day)

2. **Get API Key**
   - Settings → API Keys
   - Create new key
   - Copy the key

3. **Install Library**
   ```bash
   npm install @sendgrid/mail
   ```

4. **Configure Environment**
   ```
   SENDGRID_API_KEY=your_api_key
   SENDER_EMAIL=noreply@yourdomain.com
   ```

5. **Update Email API**
   - Update `src/app/api/emails/route.ts` to use SendGrid
   - Replace console.log with actual email sending

## PAYMENT GATEWAY (JAZZCASH)

1. **Create JazzCash Merchant Account**
   - Go to https://jazzcash.com.pk/merchants
   - Fill merchant registration form
   - Wait for approval (2-5 business days)

2. **Get Merchant Credentials**
   - Merchant ID
   - Merchant Password
   - API Key
   - Subdomain

3. **Configure Environment**
   ```
   JAZZCASH_MERCHANT_ID=your_merchant_id
   JAZZCASH_PASSWORD=your_password
   JAZZCASH_API_KEY=your_api_key
   JAZZCASH_SUBDOMAIN=your_subdomain
   ```

4. **Update Payment API**
   - Update `src/app/api/payments/route.ts`
   - Implement JazzCash API integration
   - Configure webhook for payment callbacks

5. **Test**
   - Use JazzCash sandbox before going live
   - Test with test credit cards
   - Verify callback handling

## TROUBLESHOOTING

### Build Fails
```bash
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
npm run build
```

### Database Connection Error
- Check MongoDB Atlas whitelist IPs
- Verify connection string
- Check network connectivity
- Check credentials

### High Memory Usage
```bash
pm2 monit
pm2 info shaadi-bazaar
```

### 502 Bad Gateway
```bash
pm2 logs shaadi-bazaar
pm2 restart shaadi-bazaar
sudo systemctl restart nginx
```

### SSL Certificate Issues
```bash
sudo certbot renew --dry-run
sudo certbot certificates
sudo systemctl restart nginx
```

## SCALING

### When to Scale

- Users: > 1,000 DAU
- Traffic: > 10k requests/day
- Database: > 10GB

### Scaling Options

1. **Vertical Scaling**

2. **Horizontal Scaling**
   - Load balancer (Nginx)
   - Multiple app instances (PM2)
   - Redis caching layer

3. **Database Scaling**
   - Sharding
   - Read replicas
   - Query optimization
