# 🚀 Shaadi Bazaar - Production Deployment Guide

## Option 1: Deploy to Vercel (Recommended - Easiest)

### Step 1: Prepare for Deployment

```bash
# Install Vercel CLI
npm install -g vercel

# Test build locally
npm run build

# Check for errors
npm run lint
```

### Step 2: Connect to Vercel

```bash
# Login to Vercel
vercel login

# Deploy
vercel

# Follow prompts and confirm deployment
```

### Step 3: Configure Environment Variables

In Vercel Dashboard:
1. Go to Settings → Environment Variables
2. Add:
   - `MONGODB_URI`: Your MongoDB Atlas connection string
   - `JWT_SECRET`: Your JWT secret key
   - `NEXT_PUBLIC_API_URL`: Your Vercel deployment URL

### Step 4: Setup MongoDB Atlas (Free Cloud Database)

1. Visit https://www.mongodb.com/cloud/atlas
2. Create free account
3. Create cluster (free tier)
4. Get connection string
5. Replace `MONGODB_URI` in Vercel environment variables

```
mongodb+srv://username:password@cluster.mongodb.net/shaadi-bazaar?retryWrites=true&w=majority
```

### Step 5: Custom Domain (Optional)

In Vercel Dashboard:
1. Go to Settings → Domains
2. Add your custom domain (e.g., shaadibazaar.pk)
3. Update DNS records with your domain registrar
4. SSL certificate auto-generated by Vercel

**Result**: Website live at https://yourdomain.pk ✅

## Option 2: Deploy to VPS (For Full Control)

### Prerequisites
- VPS (DigitalOcean, Linode, AWS - ~$5-10/month)
- SSH access
- Domain name

### Step 1: Setup VPS

```bash
# SSH into server
ssh root@YOUR_SERVER_IP

# Update system
apt update && apt upgrade -y

# Install Node.js (v18+)
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
apt install -y nodejs

# Install PM2 (process manager)
npm install -g pm2

# Install Nginx (reverse proxy)
apt install -y nginx

# Install MongoDB (optional - use MongoDB Atlas instead)
# OR use MongoDB Atlas cloud database
```

### Step 2: Deploy Application

```bash
# Clone your repo
git clone https://github.com/YOUR_USERNAME/shaadi-bazaar.git
cd shaadi-bazaar

# Install dependencies
npm install

# Build
npm run build

# Create .env file
nano .env.production

# Add:
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/shaadi-bazaar
JWT_SECRET=your_super_secret_jwt_key
NODE_ENV=production
```

### Step 3: Configure PM2

```bash
# Create ecosystem file
cat > ecosystem.config.js << 'EOF'
module.exports = {
  apps: [{
    name: 'shaadi-bazaar',
    script: 'node_modules/.bin/next',
    args: 'start',
    instances: 'max',
    exec_mode: 'cluster',
    env: {
      NODE_ENV: 'production',
      PORT: 3000
    }
  }]
};
EOF

# Start with PM2
pm2 start ecosystem.config.js

# Setup auto-restart on reboot
pm2 startup
pm2 save
```

### Step 4: Configure Nginx Reverse Proxy

```bash
# Edit Nginx config
nano /etc/nginx/sites-available/default
```

Replace with:

```nginx
server {
    listen 80;
    server_name yourdomain.pk;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

```bash
# Test Nginx
nginx -t

# Restart Nginx
systemctl restart nginx
```

### Step 5: Setup SSL Certificate (Let's Encrypt - Free)

```bash
# Install Certbot
apt install -y certbot python3-certbot-nginx

# Get certificate
certbot --nginx -d yourdomain.pk

# Auto-renewal
certbot renew --dry-run
```

### Step 6: Setup Auto-Deployment (GitHub Webhook)

Create deploy script:

```bash
cat > /home/deploy.sh << 'EOF'
#!/bin/bash
cd /root/shaadi-bazaar
git pull origin main
npm install
npm run build
pm2 restart shaadi-bazaar
EOF

chmod +x /home/deploy.sh
```

Create webhook endpoint (optional) for GitHub Actions.

**Result**: Website live at https://yourdomain.pk ✅

## Post-Deployment Tasks

### 1. Database Backups

**MongoDB Atlas Auto-Backup:**
- Atlas → Backup → Auto-Backup (enabled by default)
- Restore points available for 7 days

**Manual Backup:**

```bash
mongodump --uri "mongodb+srv://user:pass@cluster.mongodb.net/shaadi-bazaar" --out ./backup
```

### 2. Monitoring

```bash
# PM2 monitoring
pm2 monitor

# Logs
pm2 logs shaadi-bazaar

# Status
pm2 status
```

### 3. Performance Optimization

- Enable Gzip compression in Nginx
- Setup CDN (Cloudflare - free)
- Configure caching headers
- Setup monitoring alerts

```nginx
# Add to Nginx config
gzip on;
gzip_types text/plain text/css text/xml text/javascript application/x-javascript application/xml+rss;
```

### 4. Security Hardening

```bash
# Enable UFW firewall
ufw enable
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 3000/tcp

# Fail2ban for DDoS protection
apt install fail2ban
systemctl enable fail2ban
```

## Custom Domain Setup

### Domain Registrar (GoDaddy, Namecheap, etc.)

1. Buy domain: `shaadibazaar.pk`
2. Go to DNS settings
3. Add A record:
   - Name: `@`
   - Value: Your server IP or Vercel IP
4. Add CNAME for www:
   - Name: `www`
   - Value: `yourdomain.pk`

### Vercel Custom Domain

1. Add domain in Vercel dashboard
2. Copy nameserver addresses
3. Update registrar nameservers
4. Wait 24-48 hours for propagation

## Support & Troubleshooting

### Common Issues

**502 Bad Gateway**
```bash
# Check if app is running
pm2 status

# Restart
pm2 restart shaadi-bazaar

# Check logs
pm2 logs shaadi-bazaar
```

**Database connection fails**
- Verify MongoDB URI in .env
- Check IP whitelist in MongoDB Atlas
- Ensure firewall allows outbound connections

**Email not sending**
- Verify SendGrid/Mailgun credentials
- Check spam folder
- Review email service logs
